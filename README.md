# .github - Kreoza Organization Defaults

This repository contains organization-wide default files for the Kreoza organization.

## What's in this repository?

- **[profile/README.md](./profile/README.md):** The organization's profile README shown on the landing page.
- **[.github/ISSUE_TEMPLATE/](./.github/ISSUE_TEMPLATE/):** Standard issue templates (Bug Reports, Feature Requests) inherited by all repositories in the organization.
- **[.github/PULL_REQUEST_TEMPLATE.md](./.github/PULL_REQUEST_TEMPLATE.md):** The default pull request template for the organization.
- **[CONTRIBUTING.md](./CONTRIBUTING.md):** General contributing guidelines for all Kreoza projects.
- **[CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md):** Our community's code of conduct.
- **[SECURITY.md](./SECURITY.md):** Our vulnerability reporting policy.
- **[SUPPORT.md](./SUPPORT.md):** Where to go for help with Kreoza's projects.

## How does it work?

GitHub uses this repository to provide default values for files that are missing from other repositories in the organization. For more information, see the [GitHub documentation on organization-wide default files](https://docs.github.com/en/organizations/managing-organization-settings/setting-up-health-files-for-your-organization).
