# Kreoza

## Philosophy

Kreoza is a project that aims to power creativity by helping every individual manifest their essence.

Mission of a project is unite everyone via making them happier, using love, freedom, positivity, utility, equality, and care.

## Word meaning

`Kreoza = Create + Essence`

| Part          | Meaning     | Truth, Explanation                                                                                                                                                     |
| ------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Kre (Create)  | The action  | Everyone is an architect, artist, player, learner. We spend our time, energy, and breath building things—ideas, relationships, careers, homes, memories, and legacies. |
| Oza (Essence) | The purpose | Everything is an essence. It has its purpose(s). It is direction, it is why.                                                                                           |

## Principles

- **We all are dust in the universe:** We are small, but we are part of something big.

- **We all are equal:** We all are equal, we do not divide into people and not people. We all are entities made of little parts.

- **We all have right to be happy**

- **We all have right to be ourselves**

- **We all have right to be useful**

- **We all have right to be cared**

- **We all have right to be positive**

- **We all have right to be free**
