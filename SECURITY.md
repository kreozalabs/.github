# Security Policy

## Supported Versions

We define the versions of Kreoza's projects that currently receive security updates below.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Kreoza team takes security very seriously. We appreciate your efforts to keep the ecosystem safe.

If you find a security vulnerability, please do NOT create a public issue. Instead, report it privately.

### Where to Report

Please report security vulnerabilities via email to [security@kreoza.com](mailto:security@kreoza.com).

### Our Process

Once a vulnerability is reported, we will:

1.  Acknowledge the report within 48 hours.
2.  Work with you to understand and reproduce the issue.
3.  Fix the issue as quickly as possible.
4.  Release a new version and, if appropriate, publish a public advisory.

Thank you for helping us keep Kreoza secure!
