# Support

## Where can I find help?

We are here to support you in your creative journey with Kreoza. You can find help in several ways:

1.  **Documentation:** Check the official documentation to see if your question is already answered.
2.  **GitHub Issues:** Search through existing [GitHub Issues](https://github.com/kreoza-labs/.github/issues) for similar problems and their solutions.
3.  **Community Discussions:** Join our community for discussions about architecture, ideas, and general help. (Link here if available)
4.  **X:** Follow us [@KreozaLabs](https://x.com/kreoza) for updates.

## When should I NOT use GitHub Issues?

Please do not use GitHub issues for:

- **Security Reports:** Use the [Security Policy](./SECURITY.md).
- **General Support Questions:** If you have a question about how to do something, please use our community chat or stack overflow.

## Reporting Bugs and Feature Requests

For bug reports or feature requests, please use our predefined templates in each repository to help us understand and address your needs effectively.

Thank you for being a part of Kreoza!
